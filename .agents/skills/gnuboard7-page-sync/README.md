# Gnuboard7 Page Sync (그누보드7 페이지 동기화)

이 스킬은 분리된 프론트엔드 환경(예: Next.js)에서 구축된 메뉴와 페이지 구조를 그누보드7의 `g7_pages` (내용관리) 테이블과 자동으로 동기화해주는 Antigravity 커스텀 스킬입니다.

## 🌟 왜 이 스킬이 필요한가요?
웹사이트를 구축할 때 프론트엔드(Vercel)와 백엔드(Cafe24 등)를 분리하게 되면, 프론트엔드에서 코드로 만들어둔 수십 개의 페이지들을 백엔드 관리자 페이지에서도 관리할 수 있도록 하나하나 생성해주어야 하는 번거로움이 있습니다.

이 스킬을 사용하면:
1. 프론트엔드의 메뉴 데이터를 자동으로 읽어와서 백엔드 DB에 한 번에 빈 페이지들을 만들어 줍니다.
2. 만들어진 페이지들은 즉시 프론트엔드의 '블록 에디터'와 연동되어 내용을 작성하고 저장할 수 있게 됩니다.
3. 게시판과 일반 페이지를 정확히 구분하여 일반 페이지만 `g7_pages`에 등록합니다.

## 🚀 사용법 (How to Use)
프로젝트 진행 중, AI 에이전트에게 다음과 같이 요청하세요.

> "프론트엔드 메뉴 구조를 바탕으로 `gnuboard7-page-sync` 스킬을 사용해서 백엔드 페이지를 초기화해줘."

요청을 받은 에이전트는 자동으로 다음을 수행합니다:
1. `route.ts` 및 페이지 라우트가 `g7_pages`를 바라보도록 연동 코드를 업데이트합니다.
2. 네비게이션 데이터 추출 스크립트를 만들어 DB에 주메뉴/서브메뉴 식별자(slug)를 모두 시딩(Seeding)합니다.
3. 기존 작성된 내용이 유실되지 않도록 안전하게 업데이트합니다.

## 🏗️ 데이터 식별(Slug) 규칙
* **주메뉴 (Hub Pages)**: `카테고리명` (예: `spine`)
* **서브메뉴 (Sub Pages)**: `카테고리명-서브메뉴명` (예: `spine-lumbar-disc`)
* 페이지 내용은 블록 에디터에서 JSON 형태로 만들어져 `content` 컬럼에 실시간 저장됩니다.
