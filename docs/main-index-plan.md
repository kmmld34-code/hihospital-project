## 1. 기획 의도 및 벤치마킹 전략 (Design Strategy)

본 기획안은 두 레퍼런스 사이트의 압도적인 장점만을 선별·융합하여, **국내 최고 수준의 척추·관절·뇌신경 전문병원 웹 플랫폼**을 구축하는 것을 목표로 합니다.

```text
┌───────────────────────────────────────┐   ┌───────────────────────────────────────┐
│     [Reference 1: 인천하이병원]       │   │      [Reference 2: 바로서구병원]      │
│  - 메디컬 로열 블루 & 소프트 그레이 톤 │ + │  - 고밀도 정보 구조 & 직관적 레이아웃 │
│  - 3D 통증 부위 자가진단 인터랙션    │   │  - 10인 전문의 캐러셀 & 퀵 예약 바    │
│  - 깔끔하고 정돈된 병원 전문성       │   │  - 환자 스토리 & 시설 둘러보기 투어   │
└───────────────────┬───────────────────┘   └───────────────────┬───────────────────┘
                    │                                           │
                    ▼                                           ▼
┌───────────────────────────────────────────────────────────────────────────────────┐
│                   [ HI Hospital 차세대 웹 플랫폼 (Next.js 14+) ]                  │
│       모던 리액트 기반의 마이크로 애니메이션 + 반응형 쾌속 렌더링 + 극대화된 전환율       │
└───────────────────────────────────────────────────────────────────────────────────┘
```

### 🎯 핵심 설계 원칙 3가지
1. **신뢰감의 메디컬 컬러 시스템 (Medical Trust Color)**:
   - 차분하고 정교한 **메디컬 로열 블루(Royal Blue)**를 Primary로, 순백의 화이트 배경 위에 미세한 그레이 카드와 초미세 소프트 섀도우(Soft Shadow)를 조합하여 현대적이고 고급스러운 인상을 완성합니다.
2. **환자 중심의 즉각적 전환 동선 (Conversion-First UX)**:
   - 어디서든 3초 만에 예약/상담으로 연결되는 **플로팅 퀵 간편예약 바**와 눈에 띄는 전화상담 CTA를 적재적소에 배치합니다.
3. **인터랙티브 3D 비주얼 테크놀로지 (Interactive Health Tech)**:
   - 인천하이병원의 시그니처였던 **3D 신체 부위별 통증 자가진단 네비게이터**를 React Three Fiber / WebGL 기반의 모던 컴포넌트로 재해석하여 환자의 체류 시간과 진료과 탐색 만족도를 극대화합니다.

### 2.2 타이포그래피 (Typography)
- **Primary Font**: `Pretendard`, `-apple-system`, `BlinkMacSystemFont`, `system-ui`
- **폰트 스케일**:
  - `Hero Heading`: 48px ~ 56px (Bold, Line-height: 1.25)
  - `Section Title`: 32px ~ 38px (Bold, Line-height: 1.35)
  - `Card Title`: 18px ~ 22px (Semi-Bold)
  - `Body Text`: 15px ~ 16px (Regular, Line-height: 1.6)
  - `Caption & Badge`: 12px ~ 13px (Medium)

### 2.3 엘리베이션 및 그림자 (Shadows & Elevation)
- **Soft Card Shadow**: `box-shadow: 0 4px 20px -2px rgba(15, 23, 42, 0.06);`
- **Floating Bar Shadow**: `box-shadow: 0 12px 32px -4px rgba(7, 30, 84, 0.12);`
- **Card Hover Effect**: `transform: translateY(-4px); transition: all 0.25s cubic-bezier(0.16, 1, 0.3, 1);`

## 3. 메인 인덱스 페이지 9대 핵심 섹션 레이아웃 스펙

```text
┌────────────────────────────────────────────────────────────────────────┐

├────────────────────────────────────────────────────────────────────────┤
│ [Section 1] Hero Main Slider (대형 비주얼 + 핵심 슬로건 + 퀵 바로가기)  │

│ [Section 2] Quick Floating Bar (성함/연락처/희망과목 원클릭 간편상담신청) │
```

### [Section 0] 글로벌 네비게이션 바 (GNB & Header)
* **상단 유틸리티 바**:
  - `응급진료 24시간 정상 운영` 알림 배지 (펄스 애니메이션)
  - 대표 전화번호 `1600-8549` 원클릭 통화 연결
  - 로그인 / 회원가입 / 진료예약확인
* **메인 GNB 바 (Sticky Header)**:
  - **좌측**: HI Hospital 심볼 로고 (의료 십자가 + 세련된 모던 워드마크)
  - **중앙**: 11개 1Depth 메뉴 네비게이션 (호버 시 부드러운 풀다운 메가메뉴 표시)
    - `병원소개`, `뇌신경`, `척추클리닉`, `무릎·고관절`, `어깨관절`, `수·족부`, `외과진료`, `내과진료`, `건강검진`, `산부인과`, `커뮤니티`
  - **우측 CTA**: `온라인 진료예약` (Royal Blue 버튼, 모서리 9999px 풀 라운드 형태)

---

### [Section 1] 프리미엄 히어로 슬라이더 (Hero Section)
* **기획 배경**: 바로서구병원의 웅장함 + 인천하이병원의 세련된 의료진/장비 비주얼 융합
* **비주얼 구성**:
  - 3~4개의 고해상도 슬라이드 배너 자동 롤링 (Framer Motion 페이드/줌 트랜지션)
  - 슬라이드 1: *"응급치료부터 고난이도 척추·관절 수술까지, 정확한 진단과 치료"*
  - 슬라이드 2: *"정밀 MRI·CT 기반 원스톱 당일 검사 & 당일 판독 시스템"*
  - 슬라이드 3: *"풍부한 임상경험의 대학병원 출신 10인 전문의 협진"*
* **인터랙션**:
  - 슬라이더 하단 페이지 인디케이터(바 형태) 및 이전/다음 화살표
  - `진료예약 바로가기` / `의료진 소개 바로가기` 버튼 듀얼 배치

---

### [Section 2] 플로팅 퀵 간편예약 바 (Sticky Quick Reservation Bar)
* **기획 배경**: 바로서구병원 벤치마킹 요소 (환자의 이탈을 방지하고 예약 전환율을 극대화하는 핵심 컴포넌트)
* **디자인 및 레이아웃**:
  - 가로형 컴팩트 폼 바 (배경: Pure White + 딥 섀도우)
  - 필드 구성:
    1. **환자 성함 입력 필드** (`placeholder="성함을 입력해주세요"`)
    2. **연락처 입력 필드** (`placeholder="휴대폰 번호 (-없이 입력)"`)
    3. **진료과목 선택 셀렉트박스** (`[선택] 척추 / 관절 / 뇌신경 / 내과 / 검진 등`)
    4. **개인정보 수집 동의 체크박스** (약관 팝업 링크 포함)
    5. **[빠른 예약 신청] CTA 버튼** (로열 블루 배경, 클릭 시 즉시 백엔드 `/api/v1/appointments` 접수)
* **반응형 동작**:
  - 모바일에서는 하단 고정형(Fixed Bottom Sheet) 또는 축약된 '간편예약' 플로팅 FAB 버튼으로 자동 전환

---

### [Section 3] 3D 인터랙티브 통증 부위 자가진단 내비게이터 (Signature 3D Navigator)
* **기획 배경**: 인천하이병원의 시그니처인 **"내 통증 부위를 3D로 확인하세요"** 섹션 현대적 승계
* **구성 및 기능**:
  - **좌측/중앙**: 3D 인체 모델 비주얼 (머리/목, 어깨, 척추/허리, 무릎, 손목/발목)
    - 마우스 오버 시 해당 신체 부위가 네온 블루/시언 컬러로 하이라이트 발광(Glow)
  - **우측 패널**: 선택된 부위의 상세 질환 카드 동적 업데이트
    - 예: `목(경추)` 선택 시 ➔ 목디스크, 거북목, 일자목증후군, 경추협착증 표시
    - 예: `무릎` 선택 시 ➔ 퇴행성관절염, 십자인대파열, 반월상연골손상 표시
  - **원클릭 이동**: 해당 질환 클릭 시 즉시 세부 클리닉 상세 페이지로 이동 연결

---

### [Section 4] 10인의 전문 의료진 소개 섹션 (Doctors Spotlight)
* **기획 배경**: 바로서구병원의 "풍부한 임상경험을 가진 10인의 전문의" 벤치마킹
* **구성**:
  - **상단 카테고리 탭**: `전체`, `척추외과`, `관절정형외과`, `신경과`, `일반외과`, `내과`
  - **프로필 카드 캐러셀 (Horizontal Slider)**:
    - 의료진 전문의 고화질 전신/상반신 프로필 사진
    - 이름 및 직함 (예: `김진수 대표원장 / 정형외과 전문의`)
    - 전문 진료분야 태그 배지 (예: `#인공관절`, `#무릎내시경`, `#스포츠외상`)
    - `진료시간표 보기` 및 `예약하기` 버튼 포함

---

### [Section 5] 핵심 특화 진료센터 큐레이션 (Center of Excellence Grid)
* **기획 배경**: 병원의 대표 전문 분야 4대 센터를 2x2 또는 4열 와이드 카드로 노출
* **센터 구성**:
  1. **최소침습 척추센터**: 미세현미경 디스크 제거술, 척추내시경, 경추인공디스크
  2. **맞춤형 관절센터**: 3D 맞춤 인공관절 수술, 관절내시경, 줄기세포 연골재생
  3. **뇌신경·치매센터**: 두통/어지럼증 클리닉, 뇌졸중 골든타임 케어, 치매 조기검진
  4. **인공신장실 & 내과센터**: 고효율 최신 혈액투석 시스템, 만성질환 토탈 케어
* **스타일**: 다크 그라디언트 및 고화질 수술실/장비 이미지 배경에 글래스모피즘 오버레이 적용

---

### [Section 6] 비수술 우선 치료 & 수술 클리닉 (Treatment Philosophy)
* **기획 배경**: 인천하이병원의 "칼 대신, 정확한 시술로" 철학 계승
* **특징**: "수술은 꼭 필요한 경우에만! 환자 맞춤 1:1 보존적 비수술 요법 우선 원칙"
* **카드 그리드 (4 Column)**:
  - `01. 선택적 신경차단술 (C-arm 영상유도)`
  - `02. 체외충격파(ESWT) 재생치료`
  - `03. 1:1 전담 감압 도수·운동치료`
  - `04. 고주파 수핵 성형술`

---

### [Section 7] 환자 치료 스토리 & HI NEWS (Story & Media)
* **기획 배경**: 바로서구병원의 환자 인터뷰 썸네일과 언론보도 섹션 융합
* **구성 (2분할 레이아웃)**:
  - **좌측 (환자 치료스토리 / 유튜브 영상)**:
    - "극심했던 허리 통증, 수술 없이 걸어서 퇴원했습니다!"
    - 실제 환자 인터뷰 영상 재생 모달 및 생생한 리얼 후기 카드
  - **우측 (HI Hospital NEWS)**:
    - 주요 언론보도 기사, 방송 출연, 신규 의료진 영입 소식, 학술대회 발표 소식 리스트

### [Section 8] 첨단 의료장비 및 시설 둘러보기 (Facility Tour Gallery)
* **기획 배경**: 환자에게 시설에 대한 신뢰감을 주는 인터랙티브 갤러리
* **갤러리 탭**: `전체`, `외래진료실`, `영상진단센터(MRI/CT)`, `수술실`, `물리도수치료실`, `입원실`
* **UI**: 모던한 매스너리(Masonry) 또는 그리드 레이아웃, 클릭 시 고해상도 라이트박스 팝업 지원

### [Section 9] 진료시간 안내, 오시는 길 & 푸터 (Location & Footer)

## 5. 반응형 뷰포트 및 디바이스 전략 (Responsive Strategy)

| 디바이스 구분 | 브레이크포인트 | 레이아웃 특성 및 UX 전환 규칙 |
| :--- | :--- | :--- |
| **Desktop (데스크톱)** | `1280px ~ 1920px` | 전체 4열 그리드, 마우스 호버 메가메뉴, 3D 모델 양방향 렌더링 |
| **Tablet (태블릿)** | `768px ~ 1279px` | 2열 그리드 전환, 퀵 예약 바 컴팩트 패딩, 스와이프 터치 슬라이더 |
| **Mobile (모바일 스마트폰)** | `360px ~ 767px` | 1열 수직 스택, 하단 고정형 빠른 전화/간편예약 플로팅 바, 햄버거 메뉴 |
