│                                                                         │

### 1) 라라벨(Laravel) 기반 g7 아키텍처의 CLI 자동화 (`artisan`)
- 현재 설치된 `lsk-backend/g7` 코어는 현대적인 **Laravel 프레임워크** 위에서 동작합니다.
- 관리자 웹 화면(`admin/`)에 직접 로그인하여 수동으로 폼을 클릭해 생성할 필요 없이, **터미널 커맨드(`php artisan migrate`) 및 전용 시더(Seeder)**를 통해 백엔드 엔지니어가 코드 한 줄로 모든 게시판 테이블을 자동 프로비저닝(생성)할 수 있습니다.

### 2) 병원 특화 5대 핵심 게시판 자동 프로비저닝 명세
백엔드 마이그레이션 실행 시 다음 5대 게시판이 DB 스키마에 즉시 자동 생성 및 설정됩니다:

| 게시판 ID | 게시판 국문명 | 주요 용도 및 특징 | 보안 및 권한 설정 |
| :--- | :--- | :--- | :--- |
| `news` | 병원소식 | 병원 공지사항, 원내 행사, 언론보도 | 일반 읽기 공개 / 관리자 전용 쓰기 |
| `blog` | 의학칼럼 | 전문의 10인의 척추·관절 건강 상식 | 썸네일 지원 / 해시태그 지원 |
| `consultation` | 1:1 온라인상담 | 환자의 증상 상담 및 비공개 질문 | **비밀번호 단방향 암호화 (Bcrypt)**<br>**환자 연락처 양방향 암호화 (AES-256)** |
| `faq` | 자주묻는질문 | 예약/진료/주차/증명서 발급 FAQ | 아코디언 카테고리별 분류 |
| `non-reimbursable` | 비급여진료비 | 의료법 준수 비급여 항목 고지표 | 엑셀 일괄 업로드 및 고지일자 관리 |

### 3) 프론트엔드 연동용 초기 Mock 데이터(의학 콘텐츠) 자동 생성
- 프론트엔드 화면 개발 및 퍼블리싱 시 게시글 목록이 비어 있으면 레이아웃 검증이 불가능합니다.
- 따라서 **Laravel Database Seeder(데이터 생성기)**를 통해:
  - *"허리디스크와 척추관협착증의 결정적 차이점 (신경외과 전문의 칼럼)"*
  - *"무릎 인공관절 로봇 수술 1,000례 달성 기념 공지"*
  - *"MRI 및 초음파 비급여 수가 안내"* 등  
  실제 병원에서 사용하는 고품질 전문 콘텐츠를 자동으로 생성하여 채워 넣습니다.

## 3. 강력한 보안 및 개인정보 암호화 준수 계획 (최우선 과제)

의료 데이터 및 환자 개인정보는 법적·윤리적으로 가장 강력한 보안이 요구됩니다. 최우진 대리는 백엔드 설계 시 다음 3대 원칙을 철저히 적용합니다:

1. **상담 환자 연락처 및 인적정보 암호화**:
   - 데이터베이스 저장 직전 `AES-256-GCM` 알고리즘으로 암호화하여 DB가 유출되더라도 원문을 열람할 수 없도록 격리합니다.
2. **비밀글 패스워드 단방향 해싱**:
   - 환자가 지정한 비밀번호는 복호화가 불가능한 `Bcrypt (Cost Factor 12)` 알고리즘으로 솔팅(Salting) 후 저장합니다.
3. **API 응답 마스킹 필터링**:
   - 목록 조회 시 환자 성명(`김*별`), 연락처 뒷자리 마스킹(`010-****-1234`)을 백엔드 리소스(Resource Transformer) 단계에서 강제 마스킹하여 클라이언트에 전송합니다.

## 4. 프론트엔드(Next.js) 연동 REST API 엔드포인트 표준

프론트엔드 고윤기 대리는 다음 API 엔드포인트를 호출하여 즉시 데이터를 렌더링할 수 있습니다:

```bash
# 게시글 목록 조회 (페이지네이션, 검색어, 카테고리 필터)
GET /api/v1/boards/{board_id}/posts?page=1&limit=10&keyword=디스크

# 게시글 상세 조회
GET /api/v1/boards/{board_id}/posts/{post_id}

# 1:1 온라인 상담 등록 (비밀글 작성)
POST /api/v1/consultations
Content-Type: application/json
{
  "patient_name": "홍길동",
  "phone": "010-1234-5678",
  "subject": "다리가 저리고 엉치가 아픕니다.",
  "content": "앉아있을 때 통증이 심한데 척추 협착증일까요?",
  "is_secret": true,
  "password": "hashed_password"
}
```

## 5. 결론 및 향후 진행 계획
- 백엔드 측의 모든 준비는 독립적인 스크립트와 표준 API 규격으로 완비되어 있으므로, **대표님께서는 백엔드 설정에 대해 일절 신경 쓰실 필요가 없습니다.**
- 프론트엔드 팀(고윤기 대리)이 GNB 네비게이션 및 UI 화면을 완성해 나가는 속도에 맞추어, 최우진 대리가 백엔드 API 게이트웨이를 빈틈없이 연결하겠습니다.
