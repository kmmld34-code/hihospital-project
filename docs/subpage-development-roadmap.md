## 1. 프로젝트 개요 및 서브페이지 구축 방향성

메인 인덱스 홈(`lsk-frontend/src/app/page.tsx`) 구축 및 Vercel 배포 검증이 성공적으로 완료됨에 따라, 웹사이트의 실질적인 진료 예약 전환과 분과별 전문 의료 정보 제공을 위한 **서브페이지 확장 작업**에 착수합니다.

### 🎯 핵심 목표
1. **사용자 경험(UX) 극대화**: GNB 메뉴 및 퀵 배너 클릭 시 404 에러 없는 유기적 페이지 라우팅 연결
2. **검색엔진 최적화(SEO)**: 각 진료과목별 키워드(목디스크, 인공관절, 뇌신경 등) 맞춤 메타데이터 및 정적 페이지(SSG) 생성
3. **공통 컴포넌트 재사용(DRY 원칙)**: 표준 서브 레이아웃(`Gem_SubLayout`)을 기반으로 수십 개의 서브페이지를 신속하고 일관성 있게 구축

## 2. 서브페이지 공통 설계 원칙 (Standard Principles)

### ① 1400px 중앙 정렬 규격 준수
- 모든 서브페이지의 본문 컨테이너는 메인페이지와 동일하게 `max-w-[1400px] mx-auto px-4 sm:px-6 lg:px-8`을 엄수합니다.
- 대형 모니터(2K/4K)에서도 시선이 분산되지 않고 안정적인 가독성을 유지합니다.

### ② Gem_ 접두사 및 네이밍 컨벤션
- 새로 생성되는 모든 컴포넌트는 `Gem_SubHeader.tsx`, `Gem_Breadcrumb.tsx`, `Gem_LnbTabs.tsx`와 같이 `Gem_` 접두사를 붙여 식별성을 보장합니다.

### ③ 공통 서브 레이아웃 (Gem_SubLayout) 템플릿
서브페이지마다 중복되는 구조를 모듈화하여 단일 레이아웃 컴포넌트로 관리합니다:
```
┌──────────────────────────────────────────────────────────────┐
│ [GNB 글로벌 헤더] Gem_Header (메인과 동일 상단 고정)          │
├──────────────────────────────────────────────────────────────┤
│ [서브 비주얼 배너] Gem_SubVisual (진료과별 고화질 배경 & 타이틀)   │
├──────────────────────────────────────────────────────────────┤
│ [위치 경로 안내] Gem_Breadcrumb (홈 > 척추클리닉 > 목디스크)     │
├──────────────────────────────────────────────────────────────┤
│ [서브 탭/LNB 메뉴] Gem_SubTabs (2Depth 메뉴 가로 탭 바)        │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  [1400px 본문 영역] {children}                                │
│  - 질환 원인, 증상, 비수술/수술 치료법 안내 카드              │
│  - 담당 전문의 진료 일정 및 바로예약 CTA                     │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ [글로벌 푸터] Gem_Footer (진료시간, 고객센터, 사업자 정보)      │
└──────────────────────────────────────────────────────────────┘
```

### ④ 보안 및 개인정보 암호화 (Security First)
- 간편예약, 1:1 온라인 상담 등 환자 개인정보(성명, 전화번호, 증상)를 다루는 폼은 데이터베이스 전송 전 마스킹 및 암호화 파이프라인을 필수 적용합니다.

### ⑤ 에이전트 3인의 이미지 최적화 및 품질 원칙 (Image Optimization Architecture)
- **고윤기 (Front)**: Next.js 내장 `<Image>` 컴포넌트 사용 강제화, WebP/AVIF 자동 변환 활성화(`next.config.mjs`), LCP 대상 배너 `priority={true}` 지정.
- **박동훈 (Arch)**: 클라이언트 단 Canvas 1차 리사이징/압축 및 백엔드 그누보드7(PHP GD/Imagick) 연동 썸네일 규격화 저장 아키텍처 설계.
- **오은수 (QA)**: Lighthouse 성능 90점 이상 유지, 이미지 LCP 2.5초 이내 완료 검증, 네트워크 탭 WebP/AVIF MIME 전송 확인 필수 수행.


## 4. 세부 단계별 구현 상세 명세표

### 🚀 Phase 1: 핵심 전환 & 특화 진료센터 (Sprint 1)
가장 많은 트래픽과 진료 예약 전환이 일어나는 핵심 페이지군입니다.

| 경로 (Route) | 페이지 명칭 | 핵심 구현 요소 |
| :--- | :--- | :--- |
| `/appointments` | **온라인 진료예약** | 달력 기반 희망일자 선택, 진료과/의료진 매칭, 환자 정보 입력 및 개인정보 동의 |
| `/appointments/my` | **예약 조회/확인** | 휴대전화 본인인증 기반 실시간 예약 접수 상태 조회 및 취소 신청 |
| `/spine` | **최소침습 척추센터** | 목/허리디스크, 척추관협착증, 양방향 척추내시경(UBE), 비수술 신경차단술 안내 |
| `/knee-hip` | **맞춤형 인공관절센터**| 3D 로봇 인공관절 치환술, 무릎 반월상연골판 파열, 고관절 질환 치료 프로세스 |

---

### 🏥 Phase 2: 병원 신뢰도 구축 & 필수 가이드 (Sprint 2)
환자가 병원을 신뢰하고 안심하고 내원할 수 있도록 돕는 정보 페이지군입니다.

| 경로 (Route) | 페이지 명칭 | 핵심 구현 요소 |
| :--- | :--- | :--- |
| `/about` | **병원 소개** | 인사말, 미션/비전(환자중심 진료), 3주기 인증의료기관 획득 내역, 연혁 |
| `/about/doctors` | **10인 전문의 소개** | 서동광 원장 외 10인 전문의 상세 약력, 학술 논문 실적, 진료시간표 팝업 |
| `/about/hours` | **원내 진료시간표** | 평일, 토요일, 일요일, 공휴일 외래시간 및 각 과목별 당직 일정표 |
| `/about/directions` | **오시는 길 & 주차** | 인천 1호선 계산역 3번 출구 지도(카카오맵 API), 주차요금 및 셔틀버스 안내 |
| `/about/facility` | **첨단 시설 및 장비** | 독일 Siemens 3.0T MRI, 128채널 CT, 청정 양압 수술실 갤러리 |

---

### 🩺 Phase 3: 분과별 전문 클리닉 확충 (Sprint 3)
특화된 전문 진료과목을 완비하여 종합병원급의 위상을 구현합니다.

| 경로 (Route) | 페이지 명칭 | 핵심 구현 요소 |
| :--- | :--- | :--- |
| `/neurosurgery` | **뇌신경·치매센터** | 두통, 어지럼증, 뇌졸중(중풍) 예방, 조기 치매 스크리닝 검사 안내 |
| `/shoulder` | **어깨관절 클리닉** | 회전근개 파열, 오십견, 석회화건염 최소침습 관절경 수술 |
| `/hand-foot` | **수·족부 외상클리닉** | 무지외반증, 족저근막염, 손목터널증후군 미세신경 접합술 |
| `/surgery-general` | **외과진료 센터** | 하지정맥류, 탈장, 치질/항문클리닉 당일 퇴원 시스템 |
| `/internal-medicine`| **내과 & 인공신장실** | 고혈압/당뇨 만성질환 클리닉, 최신 NCU-18 고효율 혈액투석실 |
| `/checkup` | **종합건강검진센터** | 국가 5대 암 검진, 개인 맞춤형 종합정밀검진 프로그램 및 비용 안내 |
| `/obgyn` | **산부인과 클리닉** | 여성 부인과 질환, 자궁경부암 검진, 갱년기 토탈 케어 |

---

### 📢 Phase 4: 커뮤니티 & 고객 소통 채널 (Sprint 4)
환자와의 양방향 소통과 법적 고지 의무를 완벽히 준수합니다.

| 경로 (Route) | 페이지 명칭 | 핵심 구현 요소 |
| :--- | :--- | :--- |
| `/community/news` | **병원 소식 & 언론보도** | 원내 행사, 장비 추가 도입, 언론보도 기사 리스트 및 검색/페이징 |
| `/community/blog` | **생생 환자 치료후기** | 실제 수술/비수술 환자 감동 회복 인터뷰 및 별점 5.0 리뷰 |

| `/privacy` / `/terms` | **개인정보처리방침 & 약관** | 최신 개인정보보호법에 의거한 법적 고지 전문 |
