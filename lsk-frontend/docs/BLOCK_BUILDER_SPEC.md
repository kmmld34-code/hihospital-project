# [인천하이병원] 차세대 블록 조립형 서브관리자 빌더 시스템 헌법 및 스펙 정의서

> 대상 시스템: 서브관리자 콘솔 (Sub-Admin Component-Driven Block Builder)

## 🏛️ [총결산] 우리가 확립한 완벽한 블록 빌더 4대 헌법

### 제1조 (블록 조립형 UI 아키텍처)
1. 상단 글로벌 네비게이션(GNB): `홈으로 가기` | `컨텐츠(상세페이지) 관리` | `메인페이지 관리` | `예약 관리` | `진료시간 관리` | `원장님 소개`
2. 좌측 컴포넌트 팔레트: 우리가 개발한 핵심 컴포넌트 8종(대소제목, 가독성 텍스트, 이미지 조화, 원장님 소개, 상품형 캐러셀, 전문의 권고, 4대 질환 카드, Red Flags)을 클릭하여 본문에 실시간 추가.
3. 우측 블록 스택 캔버스: 추가된 블록들이 순서대로 적층되며, 블록마다 `[▲ 위로]` `[▼ 아래로]` `[복제]` `[삭제]` 기능으로 순서를 자유롭게 재배치.

### 제2조 (속성 변수 제어 시스템)
1. **정렬 (Alignment)**: 좌측(Left) / 중앙(Center) / 우측(Right)
2. **애니메이션 (Motion Engine)**: 기본값 100% 자동(Auto) 작동 (하이병원 표준 1.1초 글라이딩 감속 리빌). 필요 시 수동 제어.
3. **상하 여백 (Spacing)**: `standard` (80~100px) 기본 적용으로 시원시원한 호흡감 유지.
4. **배경 테마**: 화이트(#ffffff) / 하이 딥그린(#0C7657) / 살구빛 크림(#FAF5F0) / 1400px 와이드 배경 이미지.

### 제3조 (가로/세로 자동 칼정렬 - Smart Balance)
1. **가로 폭 자동 분배 (`Auto-Fit`)**: 등록된 카드 개수(1~4개)에 따라 1400px 폭 전체에 균등하게 꽉 차도록 너비를 자동 계산하여 여백 불균형(Dead Space) 원천 차단.
2. **세로 높이 바닥선 칼정렬 (`Equal Height`)**: 텍스트 길이가 달라도 부모 높이에 맞춰 카드의 세로 높이를 100% 일치시키고, 하단 버튼/치료법 라인을 바닥에 자석처럼 수평 정렬.

### 제4조 (이미지 규격 강제 틀어박힘 - Image Bounding Box Rule)
1. 관리자가 어떤 종횡비(정방형, 세로형, 가로형 직사각형)의 사진을 올리더라도 디자이너가 정한 액자 틀을 1px도 벗어나거나 찌그러지지 않도록 규격 강제.
2. 부모 컨테이너에 `overflow-hidden` 및 `rounded-2xl`을 적용하고, 내부 이미지는 `w-full h-full object-cover`로 채워 스마트 크롭 처리.
3. 1400px 와이드 모드 시 `h-[380px]` 고정 액자 내에 이미지를 가두고 텍스트를 `z-index: 10`으로 안전하게 오버레이.

## 🧩 블록 꾸러미 8대 핵심 컴포넌트 라이브러리 목록
1. `SECTION_TITLE`: 대제목 & 소제목 & 알약형 뱃지
2. `READABLE_TEXT`: 1400px 여유 가독성 텍스트 문단
3. `TEXT_WITH_IMAGE`: 텍스트 + 이미지 조화 (표준 320px vs 1400px 와이드 배경 z-index 0)
4. `DOCTOR_PROFILE`: 메인페이지 원장님 소개 컴포넌트 박스
5. `PRODUCT_CAROUSEL`: 쇼핑몰 상품형 무한 롤링 캐러셀 (우측 ➔ 좌측 이동)
6. `TIP_CALLOUT`: 💡 1400px 풀 와이드 전문의 권고 박스
7. `DISEASE_GRID`: 4대 원인질환 가로 카드 스택
8. `RED_FLAGS`: CLINICAL WARNING SIGNS 5대 위험신호 리스트
